# CISHKO

Mechanistic ODE model of CISH-knockout TIL therapy, calibrated to two murine studies and to a first-in-human phase 1 trial, with profile-likelihood identifiability analysis and the scripts that generate the manuscript figures.

Accompanies: *Modeling CISH-KO TIL therapy: T-cell persistence and endogenous competition determine response in gastrointestinal cancer.*

## Requirements and setup

Built and tested with **Julia 1.12.6**. `Manifest.toml` is committed and was generated by that version, so use Julia 1.12.x to reproduce the exact environment.

```bash
git clone <repository-url>
cd CISHKO
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

`Project.toml` and `Manifest.toml` at the repository root pin all 379 direct and transitive dependencies.

Figures 4 and 5 are produced by a Python script, `scripts/figures/figure4/plot_mouse_params_v2.py`, which needs `pandas`, `numpy` and `matplotlib`. It is not covered by the Julia environment.

## How to run a script

**Every script reads and writes plain relative filenames and expects to be run from its own directory.** Run them with `--project` pointed back at the repository root:

```bash
cd scripts/figures/figure2_3
julia --project=../../.. good_ness_plot.jl
```

Each script directory keeps its own copy of the model and input files it needs, so scripts run exactly as they did before the repository was reorganised.

## Layout

```
src/     Model and objective definitions, shared verbatim by every analysis
data/    Canonical copies of the input datasets
scripts/
  calibration/   Sequential patient fitting (final round) + uncertainty
  figures/
    figure2_3/               Figs 2 and 3
    figure4/                 Figs 4 and 5 (Python)
    figure5/                 Fig 6a-d  (folder name is legacy)
    km_figure6/              Fig 6e-h and Fig 7
    figure8_schedule_sweep/  Fig 8 + final fitting run
  supplement/    Profile-likelihood identifiability, per-patient fits, correlations
```

`src/` holds the three files that were byte-identical across all 25 copies in the
original tree — `cish_model_fun_optimized.jl`, `cish_obj_fun_patient_optimized.jl`
and `cish_obj_fun_tumor_optimized.jl`. They are the canonical reference copies;
the working copies next to each script are identical to them.

The per-experiment `main_optimized.jl` files under `scripts/calibration/exp*/`
are **not** duplicates — there are 22 genuinely different versions, each encoding
the settings for one patient pair, so they are kept separate.

### The Figure 8 dose-fractionation analysis

`scripts/figures/figure8_schedule_sweep/` is a self-contained working directory holding
the final fitting run and the dose-fractionation analysis. Run its scripts in this order:

| Script | Does | Produces |
|---|---|---|
| `schedule_sweep.jl` | Simulates each patient under 8 dosing schedules sharing one total dose | `schedule_sweep/Patient_<id>_schedule.{png,pdf}` |
| `schedule_metrics.jl` | Same sweep, extracting numbers per (patient, schedule) | `schedule_sweep/metrics.csv` |
| `schedule_heatmap.jl` | Reads `metrics.csv` | `schedule_sweep/heatmap_ratio.*` (**Fig 8a**), `heatmap_auc.*` (**Fig 8b**) |
| `schedule_plot_style.jl` | Shared colours and plot defaults | — |
| `main_optimized.jl` | The final patient fitting run | `Patient_<id>_paras.json`, `Patient_<id>_fit.{png,pdf}` |

The fractionated infusions are applied with `PresetTimeCallback` from **DiffEqCallbacks**,
which is not re-exported by `DifferentialEquations` on current versions and so is a
separate dependency; it is pinned to v4.17.0 in the root `Manifest.toml` to match the
version that produced the published figures.

This folder's `main_optimized.jl` differs from `scripts/calibration/main_optimized.jl`
only in plot styling — it applies `schedule_plot_style.jl` and saves PDF alongside PNG.
The fitting logic is unchanged and both produce byte-identical `Patient_<id>_paras.json`,
so either reproduces the calibration; this is the newer of the two.

The 24 per-patient `Patient_<id>_schedule.*` trajectory figures are excluded by
`.gitignore`; `metrics.csv` and the two heatmaps are tracked, since Fig 8 publishes
their contents.

### Superseded analyses

Model calibration was a sequential parameter reduction — 11 free parameters, then 9,
then 7. Only the final 7-parameter round (`dL, kL, pL, muL, pN, f_dose, kappa`) is
included, as `scripts/calibration/`. Rounds 1 and 2, a backup copy of the
profile-likelihood code, two abandoned exploratory analyses (PCA/SVM classification and
Sobol sensitivity), and a schedule-optimisation study that does not appear in the
manuscript are kept on disk under `_archive/` but excluded from the repository by
`.gitignore`.

The profile-likelihood analysis reported in the manuscript is the one in
`scripts/supplement/`, which reads the fitted parameter set out of each patient's JSON
(`fitted_data["vars_fit_name_patient"]`) and therefore tracks whatever fit it is pointed
at. Note that `scripts/supplement/Aggregate_Profile_delta.png` is a stale output from
round 1 — `delta` is not among the seven parameters retained in the final model.

## Patient data

The raw clinical inputs — `CISH_pt_data.xlsx` (longitudinal tumour measurements),
`cish_pt_doses.xlsx` (infused cell dose, IL-2 dosing, KO assays) and
`CISHKO_Pct_result.csv` — are individual-level trial data and are **excluded from
version control** by `.gitignore`.

The **model-derived** tables are included: per-patient fitted parameters
(`Patient_<id>_paras.json`, `patient_tumor_params*.csv`, published as Table D in S1
Text) and the simulated therapy and dose-schedule outcome tables. Two clinical columns,
`initial_tumor_size` and `cish_dose`, were removed from the tracked copies; nothing
reads them, and unmodified originals are kept in `_archive/original_parameter_tables/`.

As a result a clean clone regenerates **Figs 2 and 4–8**. Only Fig 3 cannot be
reproduced, since `good_ness_plot.jl` plots the observed clinical measurements
directly. Re-running the underlying simulations, as opposed to redrawing the figures,
still requires the restricted inputs.

The murine datasets (`Palmer2015Data.xlsx`, `CISH KO antiPD1.xlsx`, `CISH KO isotype
control.xlsx`, digitised from the published figures of the 2015 and 2022 studies) are
included.
